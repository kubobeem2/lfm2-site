# LFM2-2.6B Generated Site

このサイトの全ページは、LiquidAI の **LFM2-2.6B**（GGUF Q4_K_M、llama.cpp でローカル推論）が生成した HTML をもとに作られています。

- 計測環境: 2vCPU の仮想マシン（CPU 推論）
- 実測: prefill 31.7 tok/s / decode 11.3 tok/s（llama-bench, pp512 / tg128）
- 整形担当「おもち」がタグ構造の修復・共通ナビの付与・目次化だけを行い、本文の内容（ハルシネーション込み）は原文ママにしています
- 各ページ末尾のリンクから、モデルが生成したままの生 HTML（`originals/`）も見られます

- `index.html` — LFM2-2.6B の自己紹介とベンチマーク
- `story.html` — 短編小説「メモリの海を泳ぐ小さなAI」
- `recipe.html` — レシピ「深夜の唐揚げ」（唐揚げなのに豚ひき肉）
- `future.html` — 未来予測「2050年の日常」
